# Publication scope

This curated repository includes only project-authored wrappers, documentation and environment requirements.

Not included:

- ORDDC and RoLID-11K third-party repositories.
- Raw or converted datasets.
- YOLO/model weights and large experiment outputs.
- Real-world input videos.

Follow each upstream project and dataset license before downloading or redistributing its assets. Metrics in `docs/reproduction_report.md` are retained as historical experiment evidence and were not rerun during portfolio preparation.
